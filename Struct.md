# Structure
Structure is used when we want to allow different-different types of datatype into a single name .

## Note
- Struct keyword is used to define structure

## Syntax
    struct structure_name{
        data_type 1;
        data_type 2;
    };

## Example 
    struct emp{
        char name[50];
        int sol;
    };

## Note
- Once structure is defined, now declare variable of that type              
Ex -> Struct emp details  --> declaring a variable "details" of type emp .
