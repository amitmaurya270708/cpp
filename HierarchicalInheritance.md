# Hierarchical Inheritance
A class which conatin only one base and multiple derive class but each derive class can access base class is called hierarchical inheritance.

## Syntax
    class base{
        member of base class
    };
    class derive1:public/private/protected base{
        member of derive1 class
    };
    class derive2:public/private/protected base{
        member of derive2 class
    };
