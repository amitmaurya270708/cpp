# Constructor 
1) It allocate memory to an object.
2) The name of constructor is the same name as the class-name.
3) It is being automatically called at the time of object declaration.
4) We can pass argument through argument.
5) We can declare multiple constructor in a class.
6) Constructor can be overloaded.
7) Constructor have various types like - default , parametrized, etc.
## Syntax
    class_name(args){

    }


# Destructor
1) It de-allocate the memory of an object.
2) The name of destructor is the same name as the calss name but with preceding tilde sign(~).
3) It is automatically called at the time of object termination.
4) We can't pass any argument throgh constructor.
5) Only one destructor allows in a class.
6) But, overloading is not possible.
7) No any type of destructor.
## Syntax
    ~class_name(){

    }
