# Function Overloading
1) In function overloading we declare more than one function with same name and different type of parameters.   
Ex-  

        int sum();  
        int sum(int x);

2) It can occur without inheritance.
3) In function overloading must have different signature of function.
4) It is the concept of compile time polymorphism.
5) In Overloading every function behave differently depend upon parameter passed to them.



# Function Overriding 
1) In function overriding we declare a function in base class and derive class as same name and same parameters.   
Ex- 

        void sum();
        void sum();

2) It can occur when one class is inheritance from another class (inheritance).
3) In function overriding must have same signature of function.
4) It is the concept of runtime polymorphism.
5) In Overriding every class function explain its own behaviour.
