# Pointer 
Pointer is a variable that holds the memory address of another variable.
## Example 
    int a = 10;
    int *ptr = &a;

    cout << a;          // a = 10
    cout << ptr;        // otr = 1000
    cout << *ptr;       // *ptr = 10
    cout << &a;         // a = 1000

## Note 
- While working with pointer we need two unary operator
- EX
    - & --> Address of operator     
     and * --> Value at addresss operator
